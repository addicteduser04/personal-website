01 / PROBLEM STATEMENT

Why this work exists

Classical allocation relies on historical moments, while forecast-assisted allocation adds model risk. The project compares both ideas within one educational workflow.

Data and source material

  • Historical market data retrieved with yfinance
  • Processed return series for portfolio construction
  • Generated portfolio weights and risk/return analytics

02 / SOLUTION OVERVIEW

From input to usable output

Compare efficient-frontier allocation with ML-assisted strategies using common analytics.

    Construct mean–variance and efficient-frontier portfolios

  3. 03

  5. 05

04 / METHODOLOGY & IMPLEMENTATION

Decisions that shape the system

05 / RESULTS & EVIDENCE

What the source supports

  • It does not publish a tracked, date-bounded out-of-sample result table, so no performance advantage is claimed.

Results preserve the repository’s units, evaluation framing, and stated limitations. Missing evidence is not converted into a claim.
