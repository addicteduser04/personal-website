01 / PROBLEM STATEMENT

Why this work exists

A rental brand needs a responsive path from vehicle discovery and filtering to booking intent and reservation-status views.

Data and source material

  • Frontend demonstration data for vehicles, categories, offers, and bookings
  • Filter attributes for transmission, price, seats, fuel type, and category

02 / MY CONTRIBUTION

What I implemented

An animated frontend organizes categories, filters, reservation views and auth modals.

Implemented capabilities

  • Catalogue
  • Filters
  • Date modal
  • Reservation status
  • Responsive UI

03 / TECHNICAL APPROACH

From input to usable output

  1. 01

    Search and browse featured vehicles

  2. 02

    Filter the catalogue

  3. 03

    Open a date-based booking modal

  4. 04

    Inspect demonstration reservation status and invoice actions

04 / METHODOLOGY & IMPLEMENTATION

Decisions that shape the system

  • React 18 and Vite provide the single-page application foundation.
  • Tailwind CSS implements the responsive black/red design system.
  • Framer Motion coordinates page and component transitions.

05 / RESULTS & EVIDENCE

What the source supports

  • The repository documents a deployed responsive frontend prototype covering discovery, filters, booking intent, authentication modals, and reservation views.
  • It does not implement durable bookings, real authentication, payments, or live availability.

Results preserve the repository’s units, evaluation framing, and stated limitations. Missing evidence is not converted into a claim.

06 / CHALLENGES & LIMITATIONS

Where the evidence stops

  • Frontend demonstration data is not a production inventory source.
  • A backend API, database, authentication, payments, validation, and real-time availability remain future work.
MISSING EVIDENCE

No backend, durable reservation records, payment flow, or production operational evidence.

07 / WHAT THIS DEMONSTRATES

Engineering signal

Responsive frontend composition, interaction design, filtering, animation, and honest boundary-setting around a prototype.
